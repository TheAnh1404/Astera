# Astera Frontend to Backend API Mapping

| Page / Component | User Action | Frontend Service Method | Backend Endpoint | Request Type | Expected Response | State / Cache Invalidation | Error Handling |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Login Page | Submit Login Form | `authService.login` | `POST /api/v1/auth/login` | JSON Body `{ email, password }` | `{ user, tokens }` | Save tokens, load current user & profile | Display error code & message |
| Register Page | Submit Register Form | `authService.register` | `POST /api/v1/auth/register` | JSON Body `{ email, password, fullName }` | `{ user, tokens }` | Save tokens, navigate to `/onboarding/profile` | Display validation error or duplicate email error |
| Forgot Password | Request Reset Link | `authService.forgotPassword` | `POST /api/v1/auth/forgot-password` | JSON Body `{ email }` | `{ message }` | Show success message | Display neutral message regardless of existence |
| Reset Password | Submit New Password | `authService.resetPassword` | `POST /api/v1/auth/reset-password` | JSON Body `{ token, newPassword }` | `{ message }` | Navigate to `/login` | Token expired / invalid message |
| App Auth Restore | App Load / Refresh | `authService.getMe` & `profileService.get` | `GET /api/v1/auth/me` & `GET /api/v1/investment-profile` | Header `Authorization: Bearer <token>` | `UserRead` & `InvestmentProfileRead` | Set user & profile state in store | Token refresh attempt, auto-logout on failure |
| Investment Profile Page | Submit Profile Form | `profileService.create` / `update` | `POST` or `PATCH /api/v1/investment-profile` | JSON Body `{ capital, riskAppetite, investmentHorizon, expectedReturn, maximumDrawdown }` | `InvestmentProfileRead` | Invalidate profile, navigate to `/onboarding/analyzing` | Capital limit validation (>= 1,000,000 VND) |
| Analyzing Page | Auto Trigger | `recommendationService.generate` | `POST /api/v1/recommendations` | JSON Body `{ type: "INITIAL" }` | `RecommendationResponse` | Navigate to `/onboarding/recommendation/:id` | Show retry button & edit profile link |
| Recommendation Page | Confirm Portfolio | `recommendationService.confirm` | `POST /api/v1/recommendations/:id/confirm` | URL param `:id` | `PortfolioResponse` | Invalidate profile, recommendations, portfolio -> navigate to `/app/dashboard` | Disclaimer modal validation |
| Dashboard Page | Page Load | `portfolioService.getCurrent`, `getPerformance`, `marketService.getCurrentRegime` | `GET /api/v1/portfolios/current`, `.../performance`, `GET /api/v1/market/regime/current` | Authorization Header | Portfolio & Performance objects, Market regime | Read-only fetch | Skeleton loading, empty portfolio state fallback |
| Portfolio Page | Rebalance / Recalculate CTA | `portfolioService.recalculate` / `rebalance` | `POST /api/v1/portfolios/current/recalculate` or `rebalance` | Authorization Header | `RecommendationResponse` | Invalidate recommendations, navigate to `/app/recommendations/:id` | Show error notification |
| Market Page | Page Load | `marketService.getCurrentRegime`, `marketService.listRegimes` | `GET /api/v1/market/regime/current`, `GET /api/v1/market/regimes` | Auth Header & Query params | Regime view & Paginated regime history | Paginated cache | Error banner |
| Stock Detail Page | Page Load & Range Filter | `stockService.get` & `stockService.getHistory` | `GET /api/v1/stocks/:symbol`, `GET /api/v1/stocks/:symbol/history` | URL param `:symbol` & Query `range`, `interval` | `StockView` & `StockHistoryView` | Cache per symbol & range | Not found 404 state |
| Notifications Page | Apply Rebalance Action | `notificationService.apply` | `POST /api/v1/notifications/:id/apply` | URL param `:id` | `NotificationActionResponse` | Invalidate portfolio, versions, performance, recommendations, notifications, history | Confirmation modal & error toast |
| Notifications Page | Dismiss Rebalance Action | `notificationService.dismiss` | `POST /api/v1/notifications/:id/dismiss` | URL param `:id` | `NotificationActionResponse` | Invalidate notifications, recommendations, history | Dismiss confirmation |
| Settings Page | Save Profile / Preferences | `userService.updateMe`, `userService.updatePreferences` | `PATCH /api/v1/users/me`, `PATCH /api/v1/users/me/preferences` | JSON Body | Updated user / preferences | Invalidate user & preferences | Validation message |
